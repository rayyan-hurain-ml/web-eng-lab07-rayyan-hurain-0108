HOW TO USE THIS SOURCE (Lab 07)
1. npx create-next-app@latest web   (TypeScript, App Router, no Tailwind)
2. Copy the files from this folder into your new "web" project, replacing the ones that exist:
   next.config.ts, app/*, lib/*, data/slots.json
3. Append the lines in .gitignore.append to web/.gitignore
4. Put AI-USAGE.md in your repo root (or add the row to your existing file)
5. npm run dev  ->  http://localhost:3000
6. For Task 6:  npm run build  then  npm start
